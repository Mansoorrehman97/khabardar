Optional voice recordings (a real human voice sounds clearer than the phone's text-to-speech).

Record a teammate reading each alert message and save as MP3 here, named:

  <language>_<level>.mp3

  language = ur | en
  level    = watch | warning | evacuate

Examples: ur_warning.mp3, ur_evacuate.mp3, en_watch.mp3

If a file is missing, the phone uses its own text-to-speech voice (Urdu and English are usually available
on Android), and the written message is always shown on screen.
