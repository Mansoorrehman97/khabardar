Optional voice recordings (best quality — recommended for Pashto and Sindhi).

Record a teammate reading each alert message and save as MP3 here, named:

  <language>_<level>.mp3

  language = ur | ps | sd | en
  level    = watch | warning | evacuate

Examples: ur_warning.mp3, ps_warning.mp3, ps_evacuate.mp3, en_watch.mp3

If a file is missing, the phone uses its own text-to-speech voice (Urdu/English are usually available
on Android; Pashto and Sindhi usually are not), and the written message is always shown on screen.
